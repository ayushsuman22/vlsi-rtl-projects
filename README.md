# VLSI RTL Projects

A collection of RTL design projects developed using SystemVerilog and Verilator.

## Projects

### 1. 8-bit ALU
An 8-bit Arithmetic Logic Unit supporting arithmetic and logical operations.

**Technologies:** SystemVerilog, Verilator, RTL Design

### 2. Asynchronous FIFO
RTL implementation of an asynchronous FIFO demonstrating clock-domain crossing concepts and Gray-code pointers.

**Technologies:** SystemVerilog, Verilator, CDC, RTL Design

### 3. UART Transmitter
RTL implementation of a UART transmitter for serial data communication.

**Technologies:** SystemVerilog, Verilator, RTL Design, FSM

## Tools & Technologies

- SystemVerilog
- RTL Design
- Verilator
- Digital Logic Design
- Clock Domain Crossing (CDC)
- Finite State Machines (FSM)
